# Ghost Gallery — Bundled Ambient Audio

Place ambient MP3 files here for the Recommends slideshow feature.

## Required files:
- `ambient_soft.mp3` — Soft/gentle ambient (for birthday, highlight)
- `ambient_nostalgic.mp3` — Nostalgic/cinematic (for on this day, recap)
- `ambient_upbeat.mp3` — Upbeat/travel feel (for trip, best moment)

## Fallback
If files are missing the slideshow is generated WITHOUT audio (graceful degradation).
